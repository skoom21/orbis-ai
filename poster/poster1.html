Motivation
  • Travel planning today is deeply fragmented — users switch between 5+ platforms for flights, hotels, and activities, causing decision fatigue and missed savings.
  • Large Language Models (LLMs) have matured enough to understand complex multi-step intent and orchestrate downstream tools autonomously.
  • No existing consumer product handles dynamic mid-trip re-planning — budget changes, flight delays, and availability loss require manual rework.
  • RAG-based personalisation enables a system that learns from each interaction, improving recommendations progressively over time.

Challenges
1
Building a reliable intent routing layer — ambiguous queries must be classified correctly as the quality of the Orchestrator determines overall usability.
2
SSE streaming is architecturally significant — it constrains how LangGraph emits events and how React state is updated during multi-agent execution.
3
External API reliability — SerpApi and liteAPI can fail; circuit breakers with in-memory fallback must be in place for graceful degradation.
4
RAG context quality — retrieving too much context increases token cost and dilutes relevance; cosine thresholding and caching are essential.
5
Constraint satisfaction in real time — itinerary re-planning must complete in under 3 seconds to maintain the conversational UX.
Our Contributions
1
Domain-Specialised Multi-Agent Architecture — six ReAct agents with focused tool suites orchestrated via LangGraph StateGraph, enabling modular and extensible travel AI.
2
Live API Integration — real flight data from SerpApi and hotel availability from liteAPI v3.0; no mocked responses.
3
RAG-Based Personalisation — Gemini-embedded user preferences + travel guides retrieved via pgvector; adaptive scoring weights refined from feedback.
4
Dynamic Re-Planning Engine — constraint propagation handles budget changes, date shifts, and availability loss in real time (<3s).
5
Multi-Modal Trip Summariser — LLM narrative + interactive maps + landmark images + weather overlay generated from structured itinerary JSONB.
6
State-of-the-Art Chat Interface — SSE-streamed responses, structured flight/hotel cards, side-panel artifact display, fully responsive design.
